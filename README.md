# 読み上げプロジェクト — YomiPro

**テキストを整え、読み間違いを減らし、より自然な日本語の音声読み上げを目指す。**

## 概要

自動音声による日本語の読み上げでは、漢字の読み間違いや不自然な読み方が、文章を楽しむうえでの障害になることがあります。

**読み上げプロジェクト**は、そうした問題をできるだけ減らし、自然で聞きやすい日本語の音声読み上げを実現するための取り組みです。

秀丸マクロや Ruby スクリプトを駆使してテキストを編集し、ルビの付加や文字列の置換などによって、音声合成エンジンが正しく読みやすい文章へと整えます。

特に、Google テキスト読み上げ（Google TTS）を利用した読書環境の改善を目指しています。

## 主な取り組み

- **読み間違いの修正** — 漢字や熟語などの誤読を減らすためのテキスト処理
- **ルビによる読みの指定** — 漢字に読みを与え、意図した発音に近づける
- **文字列の置換** — 音声合成エンジンの読み方に合わせた表記の調整
- **処理の自動化と高速化** — Ruby スクリプトや秀丸マクロによる効率的なテキスト編集
- **辞書・置換リストの整備** — 読み上げ品質を改善するためのデータの蓄積と活用

## 使用している技術

- **Ruby** — テキスト処理、変換、置換処理など
- **秀丸マクロ** — テキスト編集作業の自動化
- **置換リスト・読み上げ補助データ** — 誤読対策や表記調整のためのデータ群

## このプロジェクトについて

読み上げの品質は、音声合成エンジンの性能だけで決まるものではありません。入力するテキストを工夫することでも、聞きやすさは改善できます。

日々の読書で気づいた小さな不便を一つずつ解消し、スクリプトや辞書を積み重ねながら、より快適な音声読書環境を追求しています。

このリポジトリは、そのために作成してきたスクリプト、マクロ、置換リストなどを管理するものです。
